## 1. Finder Graphite visual and search continuity

The Finder LAB progressed from the A657 search pilot through A6582–A6586 toolbar/search consolidation to A6587.1–A6587.4. The working design is matte neutral graphite, restrained steel-blue accents, no violet styling, and Finder-like search triggered by the search affordance or `Ctrl+F`. A6586 added repeat-`Ctrl+F` toggling.

- **A6587.1 Selection Mode:** operator-reported source verification and a full 189/189 C++ build PASS. The selection-mode top and bottom bars were visually improved. A file in the isolated fixtures directory moved to Trash correctly. A subsequent Settings/Trash path caused a **real SIGSEGV**, so A6587.1 is a crash-positive historical baseline, not an accepted release.
- **A6587.2 Context Menu Crash FIX:** the coredump for the crashed Finder process identified `KActionCollection::action(QString const&)`, called from `src/settings/contextmenu/contextmenusettingspage.cpp:81` via a button-click callback. A `DolphinSettingsDialog` can receive no action collection while the callback unconditionally dereferenced `m_actions`. The relevant source file was byte-identical between A6586 and A6587.1 (operator SHA-256 match), so the defect was not introduced by the selection-mode patch. A narrowly scoped candidate guards creation/use of the Shortcuts action. Operator-reported source, build and bounded GUI testing passed; the test process exited with code 0, and the operator stated that the prior scenario worked. **Long-duration soak and comprehensive regression remain pending.** Mesa/Gallium appearing in the core was not established as the root cause; later DrKonqi QML errors are not proof of the original fault.
- **A6587.3 Trash/Search State:** the first preparation stopped safely on a base-file SHA mismatch. A corrected V2 archive passed the operator's preparation and clean C++ build, and the operator confirmed the intended search behavior. A/B QSS and subsequent native/Fusion-style observations established that horizontal bands occur in **Details view**, including an empty fixtures folder. The operator chose to **retain** these normal row bands rather than treat them as a defect. Two Trash tab titles were explicitly explained by two open tabs, not duplicate UI rendering.
- **A6587.4 Footer Bridge:** the first C++ build failed because methods implemented in `finderchrome.cpp` lacked class declarations in `finderchrome.h`. A narrow V2 header fix permitted resumed build PASS (93/93). The operator's screenshot shows the visual continuation of the footer under the sidebar, with the status controls remaining in the content area. This is **visual PASS for the shown window**, not yet validated under all resizes, sidebar width changes, split view, multiple tabs or long-run stability. No status-bar widget was relocated.

The Polish tooltip `Details view mode` was observed as `Szczegółów tryb widoku`; the intended wording is **`Widok szczegółowy`**. This is a **pending Finder-private localization correction**, not a completed code or system translation change.

## 2. Dialog consistency inventory and A6588

Operator screenshots showed inconsistent appearance/ownership in file/folder selection, Properties, Open With, MIME editor, archive creation, external terminal and related context actions. The interface audit separates Finder-owned widgets, KDE Frameworks dialogs and independently launched programs; a screenshot alone does not prove process ownership.

- The A6588 source/QSS/locale audit archive was produced by the operator. ZIP structure and all four internal SHA-256 entries passed inspection.
- The report contains **364 scanned source files, 159 files with matches, 12 dialog categories, 95 external-launch matches and 1,199 localization/tooltip matches**. Match counts are potential leads, **not the number of confirmed UI bugs**.
- Confirmed source leads include an existing `FinderFileDialog` alongside `QFileDialog` call sites; `KPropertiesDialog` paths and `FinderPropertyDialogTunerV08`; separate Open With paths; KFind and Konsole launch integration; and the anomalous Details-view translation. Actual dialog ownership and usage require runtime confirmation.
- Reviewed triage: **P0** picker / Properties / Open With; **P1** archive / MIME / icons / terminal / transfer-conflict dialogs; **P2** KFind / settings / network-cloud / shared widgets. Do not globally restyle Qt/KDE or alter default MIME associations merely for visual consistency.
- The A6588.1 read-only runtime origin auditor was delivered. The operator opened its guided procedure and reached the `MIME_EDITOR` checkpoint. **No complete runtime-origin report ZIP or verified final attribution was supplied in this session.** The operator elected to restart/continue **2026-11-15**. This is a plan, not an automation.

## 3. Graphite OS — architecture decision, not a distribution release

The operator approved the design direction of **Graphite OS as an independently versioned Graphite Desktop/package layer on a maintained Fedora KDE base**. Component packaging and UI releases can be independently managed; Fedora base upgrades still require controlled compatibility/security gates and must not be represented as optional indefinitely. This is **DESIGN_ONLY**: no image, RPM repository, independent distro, operating-system package migration or installation was completed in this checkpoint.

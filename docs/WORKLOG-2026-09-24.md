## Desktop-environment plan revision

The earlier concept of maintaining two GNOME visual profiles was superseded by a stronger engineering target:

1. preserve the current accepted GNOME workstation as the canonical baseline;
2. add KDE Plasma later as an optional, reproducible alternate desktop session.

The first implementation phase must not replace GNOME or change the display manager at the same time.

The future validation scope includes:

- GNOME -> KDE -> GNOME session switching;
- rollback to the accepted GNOME baseline;
- XDG portals;
- MIME and default-application behavior;
- keyring/KWallet behavior;
- autostart interactions;
- Wayland session behavior;
- networking and Tailscale;
- audio and Bluetooth;
- removable storage;
- reproducible KDE configuration capture and restore;
- full repository verifier execution after the change.

Until those checks pass, KDE Plasma is a planned feature only and is not part of the accepted Fedora desired state.

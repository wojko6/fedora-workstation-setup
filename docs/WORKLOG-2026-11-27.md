## Local Graphite ABI Guard 0.3.0-dev3

User commands: `status`, `check`, `selftest`, `build`, `plan --manifest PATH`, `preflight --manifest PATH`, `apply --manifest PATH`.

The guard inspects embedded ABI identifiers, builds ShapeCorners using local sources, stages four managed files with SHA-256 manifests, validates production and staging hashes, and checks RPM ownership, permissions and SELinux availability. Current apply is **NOOP-only**: changed staging is rejected, not installed. A user lock prevents overlapping apply calls. The actual privileged installer and production rollback are not implemented.

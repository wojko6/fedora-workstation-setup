# Worklog — 2026-10-25: isolated local AI coding-agent laboratory

**Scope:** experimental Fedora-only coding-agent lab; **not part of the accepted workstation desired state**. The experiments use local Ollama, Qwen3.5 4B, OpenCode 1.19.4, a disposable synthetic Python repository, and rootless Podman.

**Evidence:** terminal output supplied by the human operator from the physical Fedora workstation. This page records bounded observations; it is **not** an independent audit of the host or an endorsement for use against real repositories. The laboratory scripts and unredacted logs are local operator artifacts, **not committed to this public repository**.

## Safety boundaries

- Rootless container, non-root identity, zero added capabilities, `--network=none`, SELinux Enforcing and a read-only container filesystem apart from explicitly controlled temporary/workspace paths.
- No general-purpose shell execution by the model; only specifically permitted `read` and `edit` calls after host-side tool declaration filtering and argument/path validation.
- Only synthetic source and test files are exposed. The project under test is a disposable copy; the reference Git worktree stays clean.
- Model traffic reaches the local host Ollama through an explicitly controlled file-mailbox relay. The model container cannot directly access host Ollama over TCP.
- No `sudo`, new installs, systemd/SELinux configuration changes, production mounts, router contact or changes to RouterCloud/DUFS.
- **Promotion decision:** `DEPLOYMENT_GATE=HOLD` across all stages. Successful synthetic tests do not authorize unattended writes to production repositories.

## Proposed next gate — V0.18

The goal is to separate *structurally permitted edits* from *semantically correct changes*, allowing the model to select a solution within two tightly scoped expressions, while enforcing independent tests. The structural policy should reject unauthorized files, added statements/imports, dangerous operations, symlinks and unreviewed scope changes. A structurally allowed but incorrect logic change must fail the independent regression and end as **HOLD**.

**Not completed on 2026-10-25:** real Fedora `--inspect`, `--test`, and `--run` for V0.18; generalized repository permissions; human approval workflow for real patches; trust and threat assessment of ADB or external devices; use against production infrastructure.

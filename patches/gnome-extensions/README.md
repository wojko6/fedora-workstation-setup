# GNOME extension patches

Only verified local modifications belong here.

Do not copy entire third-party extensions merely because their files have recent modification timestamps. Prefer a small source patch or translation source (`.po`) tied to a known upstream version. Generated `.mo` files can be rebuilt during setup when source translations are available.

Candidate localizations observed during inventory include Polish catalogs for Add to Desktop, Blur My Shell, Clipboard Indicator, and ddterm. They must be compared with their upstream versions before being classified as local patches.

# Daily worklogs

Daily worklogs record accepted end-of-day checkpoints without replacing `PROJECT-STATUS.md`.

## Layout

Use:

```text
daily/YYYY/MM/YYYY-MM-DD.md
```

Each completed worklog should capture:

- scope of work completed that day;
- important implementation or recovery decisions;
- verifier and repository-consistency results;
- commits or publication state when relevant;
- unresolved items carried forward;
- an explicit end-of-day status.

The worklog is historical evidence. The current canonical desired state remains defined by the repository configuration and summarized in `PROJECT-STATUS.md`.
